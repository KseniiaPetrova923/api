# Testing REST and SOAP API in Postman

I tested the API requests for the online store "Demo-Shopping" using the [Swagger documentation](https://qa.demoshopping.ru/api-docs/). For some requests, I created scripts that check the status code, response time, environment compliance, data type and keys in the response body.
